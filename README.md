# Casino Run

An arcade casino with fictional money: six minigames, a shared balance, items and a ticking goal. Play it in the browser at [casinorun.fun](http://casinorun.fun).

## Nintendo 3DS

Install straight to a 3DS with custom firmware (Luma3DS) and **FBI**:

1. Connect the 3DS to Wi-Fi and open FBI.
2. **Remote Install → Scan QR Code**, then point the camera at this code.
3. Confirm the install. Casino Run appears on the HOME Menu.

<img src="docs/3ds/install-qr.png" alt="QR code: download casino-run.cia" width="240">

The code links to `https://github.com/JustGoodinc/Casino-Run/releases/latest/download/casino-run.cia`, so it always installs the newest release. Manual install and build steps: [docs/3ds/INSTALL.md](docs/3ds/INSTALL.md).
